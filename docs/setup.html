Bắt đầu

Tải và cài đặt iAtlas

Chuẩn bị tài khoản Claude, cài app, để iAtlas tự tải công cụ phân tích lần đầu. Bạn không cần cài JDK, Homebrew hay Python hệ thống. Nút Tải iAtlas góc trên bên phải đã chọn bản phù hợp máy bạn.

Yêu cầu

Hạng mục Chi tiết
Máy macOS (Apple Silicon hoặc Intel) hoặc Windows x64. Chưa hỗ trợ Linux.
Tài khoản AI Claude Pro hoặc Max (khuyến nghị) để dùng Claude Code CLI; hoặc Anthropic API key trong Settings. Có thể cấu hình thêm OpenAI / Gemini sau.
Claude Code Cài Claude Code trên máy, mở terminal chạy claude rồi /login với tài khoản Pro/Max.
Mạng Cần mạng lần đầu (tải Python ~30 MB, Playwright, Chromium ~300 MB, hermes-dec), khi gọi AI, và khi tải APK / crawl web.
Không cần JDK, Homebrew, Python hệ thống, apktool, jadx — app tự kèm hoặc tự tải.

Hướng dẫn theo hệ điều hành

Tab mặc định theo máy bạn đang dùng. Đổi tab nếu cần cài trên máy khác.

  1. Tải bộ cài (DMG) Bấm Tải iAtlas góc trên phải — trình duyệt tải thẳng iAtlas-1.0.0-macos-arm64.dmg (bản v1.0.0). Các bản khác xem Releases.
  2. Cài app Mở file DMG → kéo iAtlas vào thư mục Applications. Nếu Gatekeeper chặn (app chưa codesign): System Settings → Privacy & Security → Open Anyway, rồi mở lại app.
  3. Cài Claude Code và đăng nhập Làm theo hướng dẫn Anthropic để cài CLI. Trong Terminal: claude → /login với tài khoản Pro/Max. Kiểm tra lệnh có trong PATH (thường ~/.local/bin/claude hoặc /opt/homebrew/bin/claude). Không dùng CLI: chuẩn bị Anthropic API key để dán trong Settings.
  4. Mở iAtlas — setup lần đầu Màn Setting up iAtlas tự kiểm tra/tải: toolchain, Python, Playwright, Chromium, hermes-dec. Có thể Retry hoặc Continue anyway nếu một phần lỗi.
  5. Settings (AI) & dữ liệu Vào Settings xác nhận Claude CLI hoặc API key. Workspace: ~/.ai-crawler/ (tools, work, output, config).
Quyền trên macOS

Cần mạng và ghi file vào ~/.ai-crawler/. Chromium có thể hỏi lần đầu. Không cần Accessibility / Full Disk Access.

  1. Tải bộ cài (DMG Intel) Dùng nút tải góc trên → Releases, chọn version rồi tải iAtlas-*-macos-x64.dmg khi có bản Intel.
  2. Cài app Mở DMG → kéo iAtlas vào Applications. Nếu bị chặn: System Settings → Privacy & Security → Open Anyway.
  3. Cài Claude Code và đăng nhập Cài Claude Code → Terminal: claude → /login (Pro/Max). PATH thường: ~/.local/bin/claude hoặc /usr/local/bin/claude. Hoặc dùng Anthropic API key trong Settings.
  4. Mở iAtlas — setup lần đầu Đợi màn setup tải toolchain / Python / Playwright / Chromium / hermes-dec. Có thể bỏ qua phần lỗi và vào app.
  5. Settings (AI) & dữ liệu Kiểm tra Claude CLI hoặc API key. Dữ liệu tại ~/.ai-crawler/.
Quyền trên macOS

Giống Apple Silicon: mạng, ghi ~/.ai-crawler/, có thể hỏi Chromium lần đầu.

  1. Tải bộ cài (MSI) Bấm Tải iAtlas → Releases, chọn version rồi tải iAtlas-*-windows-x64.msi khi có bản Windows.
  2. Cài app Chạy file MSI, làm theo wizard. Nếu SmartScreen cảnh báo: More info → Run anyway (bản nội bộ chưa ký số có thể gặp).
  3. Cài Claude Code và đăng nhập Cài Claude Code theo docs Anthropic (Windows). Mở PowerShell hoặc Command Prompt: claude → /login với Pro/Max. Đảm bảo CLI có trong PATH. Hoặc dùng Anthropic API key trong Settings của iAtlas.
  4. Mở iAtlas — setup lần đầu Màn setup tự tải Python, Playwright, Chromium, hermes-dec (và toolchain nếu cần). Có thể Continue anyway nếu một phần fail.
  5. Settings (AI) & dữ liệu Vào Settings xác nhận AI. Workspace thường tại %USERPROFILE%\.ai-crawler\ (tools, work, output, config).
Lưu ý Windows

Cần mạng lần đầu và khi gọi AI / tải APK. Firewall có thể hỏi khi Chromium hoặc app kết nối mạng — cho phép nếu dùng crawl web.

Sau khi vào app (mọi OS)

  • Màn setup xong → Home (Agent). Tạo project APK hoặc Web rồi chạy pipeline.
  • Chi tiết thao tác hàng ngày: xem Hướng dẫn sử dụng.
Lưu ý Claude “permissions”

Trong Settings có tùy chọn permission mode của Claude Code (agent chạy công cụ trong workspace). Đây không phải quyền hệ thống macOS/Windows — chỉ ảnh hưởng phê duyệt thao tác trong phiên agent.
