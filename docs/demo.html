Demo

Một lần dùng iAtlas kể bằng ảnh: tạo project cho app muốn xem, đợi phân tích xong, rồi hỏi bằng tiếng thường. Bấm vào ảnh bất kỳ để xem cỡ lớn.

Tạo project → Chạy phân tích → Hỏi agent

Đọc một app Android

Chỉ cần package name của app trên Google Play. iAtlas tự tải file cài đặt về máy bạn rồi phân tích, không đụng đến điện thoại.

01

Tạo project APK

Chọn Type: APK, để nguồn là Store (hoặc This computer nếu bạn đã có sẵn file APK), dán package name dạng com.example.app rồi bấm Create project. Ô Name chỉ để dễ nhận ra project trong danh sách.

02

Pipeline chạy xong 4/4

Bốn bước tự động: tải app → giải nén → nhận diện công nghệ → quét phần lõi.

03

Hỏi một câu thật

Ảnh chụp trên máy thật, không dựng

Mọi ảnh ở trang này chụp từ iAtlas đang chạy. Tên app và tên miền trong ảnh có thể được làm mờ khi liên quan đối tác.

Cho người quản trị trang: cách thêm ảnh demo

Mỗi ô ảnh trên đọc đúng một file trong docs/assets/demo/. Ô nào chưa có file thì hiện khung chờ kèm tên file cần đặt — thả ảnh vào đúng tên đó, reload trang là hiện, không phải sửa HTML.

  1. assets/demo/apk-new-project.png — hộp thoại New project, loại APK.
  2. assets/pipeline-done.png — màn Agent khi pipeline xong 4/4.
  3. assets/chat-example.png — agent trả lời một câu hỏi thật.

Ảnh nên chụp cửa sổ app ở chiều rộng ~1440px, định dạng PNG, che thông tin nhạy cảm trước khi commit.
