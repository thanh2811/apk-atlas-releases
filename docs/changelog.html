Changelog

Mỗi bản cài đặt có gì mới, cải thiện gì và sửa lỗi gì — viết bằng tiếng thường. Muốn biết mình đang dùng bản nào: trên macOS bấm chuột phải iAtlas trong Applications → Get Info; trên Windows xem Properties → Details của file cài đặt.

Cách cập nhật

iAtlas chưa tự cập nhật. Tải bộ cài mới nhất rồi cài đè lên bản cũ: macOS kéo lại vào Applications và chọn Replace, Windows chạy lại file EXE. Dự án, chat và dữ liệu đã crawl nằm trong thư mục ~/.ai-crawler nên không bị mất khi cài đè.

  1. 1.0.1

    Mới nhất 10/08/2026

    Thêm app từ file có sẵn trên máy, chọn được văn phong trả lời của trợ lý, và thấy rõ tiến độ khi app đang được nạp.

    Mới
    • Thêm app từ máy của bạn. Kéo thả file APK vào ô New project, hoặc chọn qua cửa sổ file — dùng cho app nội bộ, app chưa phát hành hoặc app khoá theo quốc gia mà store không tải được. Tên gói được đọc thẳng trong file nên bạn không cần biết trước, và file .apks / .xapk được tự bung về bản APK gốc.
    • Chọn người đọc câu trả lời. Ngay trong khung chat có hai chế độ: Non-tech (mặc định, ngôn ngữ đời thường) và Developer (ngôn ngữ kỹ thuật, kèm đường dẫn file và đoạn mã). Chỉ cách diễn đạt đổi — kết luận và các giá trị bạn cần vẫn y nguyên. Lựa chọn được nhớ cho lần mở sau.
    • Thấy tiến độ khi đang nạp app. Khung chat hiện thanh tiến độ ở giữa trong lúc tải hoặc chép app vào dự án, thay vì trông như đang đứng yên.
    Cải thiện
    • Trợ lý chat mặc định chạy Sonnet: nhanh và rẻ hơn khoảng 40% mỗi lượt so với Opus, chất lượng tương đương cho việc đọc mã app và dò API. Ai đã tự chọn model khác thì giữ nguyên lựa chọn đó.
    • Bỏ bước tự tóm tắt hội thoại — tốn thêm chi phí mà không lợi gì, vì phiên Claude Code đã tự quản lý ngữ cảnh.
    • Tải file và chạy pipeline được đưa ra khỏi luồng giao diện, app không còn khựng khi đang xử lý.
    • Ẩn các bước pipeline không dùng đến; thông báo “đã xong” hiển thị rõ hơn.
    Sửa lỗi
    • Sửa lỗi khiến việc tải app trong bản cài đặt chết ngay khi vừa bắt đầu.
    • Sửa lỗi bản cài đặt mở lên rồi tắt ngay do thiếu thành phần đọc dữ liệu JSON.
    • Bộ cài đóng gói lại ổn định, và danh sách công cụ đi kèm ghi đúng phiên bản Java thực sự được đóng gói.
    Tài liệu
    • Viết lại trang giới thiệu, cài đặt và hướng dẫn; nút tải trỏ thẳng tới file cài đặt.
    • Thêm chính trang Changelog này để theo dõi phiên bản.

    Bộ cài: iAtlas-1.0.1-macos-arm64.dmg · bản Windows của 1.0.1 chưa phát hành — dùng bản 1.0.0 bên dưới.

  2. 1.0.0

    05/08/2026

    Bản phát hành đầu tiên cho nội bộ iKame Global.

    Mới
    • Dự án APK. Nhập package name của app Android, iAtlas tải app về, phân tích tĩnh trên máy bạn rồi trả lời câu hỏi trong khung chat.
    • Dự án Web. Nhập địa chỉ website; có trình duyệt tích hợp để bạn tự vượt Cloudflare/CAPTCHA khi cần rồi trả lời done cho agent chạy tiếp.
    • Hỏi bằng tiếng thường. Kết quả xuất được dạng bảng, CSV, JSON schema hoặc diagram theo đúng định dạng bạn yêu cầu.
    • Danh mục API. Endpoint, header bắt buộc, tham số và schema request/response gom về một tab.
    • Bộ cài macOS Apple Silicon và Windows x64, kèm sẵn công cụ phân tích — không phải cài thêm gì.

    Bộ cài: iAtlas-1.0.0-macos-arm64.dmg · iAtlas-1.0.0-windows-x64.exe
