Hỗ trợ

Câu hỏi thường gặp

Lỗi AI, setup chậm, tải APK thất bại, và chỗ lưu dữ liệu. Không hết lỗi? Gửi mail hỗ trợ bên dưới.

Agent không trả lời / lỗi Claude

  • Thường là chưa đăng nhập Claude. Mở lại app: màn setup sẽ hiện nút Log in to Claude — bấm và đăng nhập tài khoản Pro hoặc Max trên trình duyệt.
  • Vào Settings kiểm tra mục Claude: đường dẫn Claude Code, hoặc tắt CLI và dán Anthropic API key.
  • Kiểm tra mạng / proxy nội bộ có chặn không.

Setup tải Chromium chậm hoặc fail

  • Chromium ~300 MB — đợi hết hoặc bấm Retry.
  • Có thể Continue anyway: app vẫn mở; crawl Web có thể chưa dùng được cho đến khi Chromium sẵn sàng.
  • Project APK thường vẫn chạy nếu toolchain + Python ổn.

Không tải được APK

  • Kiểm tra đúng package name (dạng com.xxx.yyy) và kết nối mạng.
  • Nguồn tải phụ thuộc dịch vụ bên thứ ba — có thể tạm lỗi; thử lại sau hoặc hỏi agent bước tiếp.
  • Nếu đã có file APK trong workspace từ lần trước, pipeline có thể dùng bản đã cache.
  • Đã có sẵn file APK trên máy: tạo project mới, chọn nguồn This computer rồi kéo file vào.

Chat bị khoá, chỉ hiện bảng “Preparing…”

  • Project APK phải chuẩn bị xong thì ô chat mới mở — đợi đến khi bảng tự đóng.
  • Thấy Waiting for … to finish hoặc Queued: một project khác đang được chuẩn bị, project này tự chạy ngay sau đó.
  • Một bước bị lỗi: bấm Try again, hoặc Open chat anyway để hỏi luôn với phần đã có.
  • Hiện has no app yet: lúc tạo bạn đã tắt tải sẵn — bấm Get & prepare the app.

Không thấy tab APIs / Browser nữa?

Từ bản 1.0.6, mỗi khung chat chỉ còn nút gạt Agent / Sources. Danh sách API, script và dữ liệu agent làm ra đều nằm trong khung Output bên phải — cứ hỏi agent bằng tiếng thường. Xem màn làm việc.

Cloudflare / CAPTCHA trên project Web

Agent tự chờ cho phần lớn trang xác minh tự qua trong trình duyệt có sẵn của iAtlas. Nếu vẫn bị chặn, agent sẽ nói rõ trong chat cần bạn làm gì — trả lời ngay trong ô chat. Không cần copy cookie thủ công.

Dữ liệu nằm ở đâu?

Thư mục gốc: ~/.ai-crawler/

  • tools/ — công cụ đã tải
  • work/ — từng project (smali, chat, artifact tạm)
  • output/ — kết quả crawl / report / script; mỗi việc một thư mục <project>/<thời điểm>-<tên việc>/, xem ngay ở khung Output bên phải màn Agent
  • config/ — settings (ví dụ settings.properties)

Xóa / đổi tên / nhân bản project

Ở cột trái màn Agent, rê chuột vào tên project rồi bấm ⋯ → Rename, Duplicate project hoặc Delete project. Xóa project sẽ xoá thư mục làm việc và lịch sử chat của project đó — cân nhắc trước khi xác nhận.

Muốn tách hai hướng phân tích cho cùng một app: dùng Duplicate project, hoặc tạo project mới với cùng package name — iAtlas làm thêm một project riêng (nếu để trống ô Name, tên tự đánh số như “Tên (2)”) và dùng lại file APK đã tải.

Đổi model hoặc nhà cung cấp AI

Vào Settings: Claude CLI (mặc định) hoặc API key Anthropic; có thể cấu hình thêm OpenAI / Gemini nếu team cho phép. Đổi model / effort tại đây rồi thử lại chat. Cũng đổi nhanh được ngay ở hàng dưới ô chat.

macOS báo không mở được app

App có thể chưa codesign. Vào System Settings → Privacy & Security, chọn Open Anyway, rồi mở lại iAtlas.

APK vs Web — chọn cái nào?

  • APK — đối thủ là app hoặc game Android; cần flow in-app, kinh tế / IAP, API backend, nội dung trong app.
  • Web — đối thủ / nguồn là website hoặc web app; cần crawl trang và traffic trình duyệt.

  5. Trang bảo mật / tuân thủ nội bộ.

  7. Bản tiếng Anh.
