Hỗ trợ

Câu hỏi thường gặp

Lỗi AI, setup chậm, tải APK thất bại, và chỗ lưu dữ liệu. Không hết lỗi? Gửi mail hỗ trợ bên dưới.

Agent không trả lời / lỗi Claude

  • Thường là chưa đăng nhập Claude. Mở lại app: màn setup sẽ hiện nút Log in to Claude — bấm và đăng nhập tài khoản Pro hoặc Max trên trình duyệt.
  • Vào Settings kiểm tra mục Claude: đường dẫn Claude Code, hoặc tắt CLI và dán Anthropic API key.
  • Kiểm tra mạng / proxy nội bộ có chặn không.

Setup tải Chromium chậm hoặc fail

  • Chromium ~300 MB — đợi hết hoặc bấm Retry.
  • Có thể Continue anyway: app vẫn mở; crawl Web và Browser có thể chưa dùng được cho đến khi Chromium sẵn sàng.
  • Project APK thường vẫn chạy nếu toolchain + Python ổn.

Không tải được APK

  • Kiểm tra đúng package name (dạng com.xxx.yyy) và kết nối mạng.
  • Nguồn tải phụ thuộc dịch vụ bên thứ ba — có thể tạm lỗi; thử lại sau hoặc hỏi agent bước tiếp.
  • Nếu đã có file APK trong workspace từ lần trước, pipeline có thể dùng bản đã cache.

Cloudflare / CAPTCHA trên project Web

  1. Mở tab Browser.
  2. Hoàn thành challenge trên trang.
  3. Trong Agent chat, trả lời done.

Không cần copy cookie thủ công.

Dữ liệu nằm ở đâu?

Thư mục gốc: ~/.ai-crawler/

  • tools/ — công cụ đã tải
  • work/ — từng project (smali, chat, artifact tạm)
  • output/ — kết quả crawl / report / script
  • config/ — settings (ví dụ settings.properties)

Xóa / đổi tên project

Trên sidebar Context: dùng dialog rename / delete của project. Xóa project sẽ dọn dữ liệu liên quan trong workspace — cân nhắc trước khi xác nhận.

Đổi model hoặc nhà cung cấp AI

Vào Settings: Claude CLI (mặc định) hoặc API key Anthropic; có thể cấu hình thêm OpenAI / Gemini nếu team cho phép. Đổi model / effort tại đây rồi thử lại chat.

macOS báo không mở được app

App có thể chưa codesign. Vào System Settings → Privacy & Security, chọn Open Anyway, rồi mở lại iAtlas.

APK vs Web — chọn cái nào?

  • APK — đối thủ là app hoặc game Android; cần flow in-app, kinh tế / IAP, API backend, nội dung trong app.
  • Web — đối thủ / nguồn là website hoặc web app; cần crawl trang và traffic trình duyệt.

Đề xuất nội dung docs sắp tới

Các mục nên bổ sung (cũng liệt kê trên trang Giới thiệu):

  1. Thư viện prompt mẫu theo kịch bản sản phẩm.
  2. Glossary thuật ngữ tiếng thường.
  3. Screenshot & video onboard.
  4. Checksum SHA256 cho từng file cài (changelog đã có ở trang Changelog).
  5. Trang bảo mật / tuân thủ nội bộ.
  6. Troubleshooting log nâng cao.
  7. Bản tiếng Anh.
