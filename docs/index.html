Tài liệu người dùng

iAtlas

App desktop giúp đội sản phẩm, nội dung và kỹ thuật phân tích app đối thủ (và website) qua giao diện chat — không cần biết reverse engineering. Trước đây PM thường phải subscribe app đối thủ để xem full flow, giờ có thể kiểm tra qua static analysis code nhanh hơn và chủ động hơn.

Dành cho ai?

PM BA Content Dev Client / BE

Bạn hỏi bằng tiếng thường; iAtlas trả lời theo kết quả và bước tiếp theo, kèm đúng tên API, header hay đường dẫn khi cần.

Công dụng

Phân tích flow đối thủ

PM/BA chủ động xem luồng app: IAP, IAA, tracking, rating, onboarding và các kịch bản sản phẩm khác — không cần nhờ Dev “mổ” app.

Luồng tính năng & diagram

Phân tích chi tiết một tính năng, rồi nhờ agent mô tả hoặc vẽ diagram hoạt động (sequence, flow) theo format bạn muốn.

Spy / crawl nội dung

Đội Content lấy nội dung từ app hoặc web đối thủ để tham khảo cấu trúc, taxonomy, copy — qua pipeline crawl và hỏi agent.

API graph & schema cho Dev

Dev Client/BE xem danh sách API, request/response, quan hệ endpoint, và draft cấu trúc database từ dữ liệu đã phân tích.

Chat — output đúng format

Hỏi đáp trong app dạng chat. Yêu cầu xuất bảng Markdown, CSV, JSON schema, checklist BA, hay bất kỳ cấu trúc nào bạn chỉ định.

Hai loại dự án

APK

Phân tích app Android theo package name (ví dụ com.example.app). App tự tải APK (nếu bật), phân tích tĩnh và chuẩn bị crawl nội dung / API.

Web

Phân tích website từ URL gốc. Dùng trình duyệt tích hợp; nếu gặp Cloudflare/CAPTCHA bạn hoàn thành trên tab Browser rồi trả lời done.

Không cần thiết bị thật hay máy ảo

Phân tích app dựa trên file APK và công cụ tĩnh trên máy bạn. Không yêu cầu root, Frida, hay copy token từ điện thoại.

Nên bổ sung gì vào docs?

Các mục đề xuất cho lần cập nhật sau — giúp onboard nhanh hơn:

  1. Thư viện prompt mẫu theo kịch bản (IAP, IAA, rating, tracking, onboarding).
  2. Glossary thuật ngữ bằng tiếng thường (package name, API graph, pipeline…).
  3. Ảnh chụp màn hình Setup / Home / APIs / Browser / Output.
  4. Video ngắn 3–5 phút: từ cài app đến crawl APK đầu tiên.
  5. Changelog / phiên bản gắn với file cài đặt.
  6. Trang bảo mật & tuân thủ nội bộ iKame (phạm vi dùng, bản quyền nội dung).
  7. Troubleshooting nâng cao (log trong ~/.ai-crawler, Settings).
  8. Bảng so sánh khi chọn project APK vs Web.
  9. Bản tiếng Anh nếu onboard contractor nước ngoài.
  10. Link tải chính thức + checksum SHA256 theo từng OS.
