Hiểu app và game đối thủ
chỉ bằng cách hỏi

iAtlas là app desktop đọc hộ bạn bên trong app Android, game và website đối thủ, rồi trả lời bằng tiếng thường ngay trong khung chat. Không cần biết kỹ thuật, không cần điện thoại, không cần subscribe app hay mua IAP trong game đối thủ chỉ để xem họ làm flow gì.

  • Hỏi tiếng Việt — trả lời theo kết quả và việc cần làm tiếp
  • Xuất bảng, CSV, JSON schema hay diagram theo format bạn yêu cầu
  • Chạy hoàn toàn trên máy bạn, phân tích tĩnh — không root, không máy ảo

Trước khi có iAtlas — và giờ giải quyết thế nào

Cùng một bài toán cho team app và team game: hiểu đối thủ mà không phải chơi tay, subscribe, mua IAP hay chờ Dev mổ build.

Trước đây

  • PM app: tải về, bấm tay từng màn để đoán luồng — tốn thời gian mà vẫn thiếu. Logic ẩn (mở khoá, paywall, lúc chèn ads) test tay không phủ hết. Nhiều flow còn phải subscribe gói trả phí mới thấy.
  • PM game: tải về, chơi tay từng màn để đoán luồng — tốn thời gian mà vẫn thiếu. Logic ẩn (hết lượt thì hiện ads, lúc nào bán gói, phần thưởng mỗi ngày) chơi tay không phủ hết. Nhiều flow còn phải xem ads hoặc mua gói của đối thủ mới thấy.
  • Content: mở từng màn, từng item để đọc thủ công.
  • Dev / Game Dev: tự dò API, schema; game thì dump IL2CPP / grep smali, map SDK ads–IAP hộ PM.

Với iAtlas

Dán package name Google Play, kéo thả APK, hoặc dán URL website — app tự phân tích rồi báo xong. Sau đó hỏi thẳng bằng một câu:

  • Vẽ sơ đồ bao quát toàn bộ luồng và các trường hợp trong app / game đối thủ.
  • Truy vết tính năng ẩn: flow kiếm tiền (IAP), vị trí quảng cáo (IAA), điều kiện rẽ nhánh. Game cũng vậy — lúc hết lượt hiện ads, lúc bán gói, phần thưởng mỗi ngày.
  • Cần content: một câu prompt, iAtlas viết script crawl, kéo dữ liệu về máy.
  • Dev có sẵn danh mục API, schema, API graph. Game Dev có logic + class đã khôi phục, SDK map — khỏi tự dò.

Dành cho ai?

PM, BA, Content, Dev — và cả PM game cùng Game developer — dùng chung một app, hỏi những câu khác nhau. App thường hay game đều đọc được.

PM

Product Manager

Xem đối thủ đang làm gì mà không phải chờ Dev “mổ” app.

  • Flow kiếm tiền: gói IAP, thời điểm hiện offer, màn paywall, điều kiện mở khoá.
  • Quảng cáo (IAA): vị trí hiển thị, loại ad, khi nào chèn giữa luồng.
  • Flow hoạt động của từng tính năng: tính năng của app đối thủ chạy thế nào, màn nào nối màn nào, điều kiện để mở.
  • So sánh nhanh: đối chiếu tính năng đối thủ với backlog của mình trước khi quyết định làm.
GAME

PM Game

Xem game đối thủ đang làm gì mà không phải chờ Dev “mổ” game.

  • Flow kiếm tiền: gói mua trong game, thời điểm hiện offer, lúc hết lượt / hết mạng thì hỏi mua.
  • Quảng cáo (IAA): vị trí hiển thị, xem ads để tiếp tục chơi / thêm vật phẩm / nhân đôi thưởng.
  • Flow hoạt động của từng tính năng: một ván chơi chạy thế nào, màn nào nối màn nào, điều kiện để mở.
  • So sánh nhanh: đối chiếu tính năng đối thủ với backlog của mình trước khi quyết định làm.
BA

Business Analyst

Biến một tính năng của đối thủ thành tài liệu dùng được ngay.

  • Mô tả luồng chi tiết: từng bước, điều kiện rẽ nhánh, trạng thái lỗi.
  • Diagram: sequence / flow chart vẽ tự động theo format bạn chọn.
  • Checklist & acceptance criteria: xuất thẳng dạng danh sách để đưa vào ticket.
  • Bằng chứng đi kèm: mỗi kết luận có nguồn trong file đã phân tích, không đoán mò.
CT

Content

Lấy dữ liệu nội dung của đối thủ để tham khảo cấu trúc và cách viết.

  • Crawl nội dung: danh sách bài / sản phẩm / mục từ app hoặc website đối thủ.
  • Taxonomy: họ chia chuyên mục, tag, bộ lọc như thế nào.
  • Cấu trúc bài viết: các trường tiêu đề, mô tả, ảnh, độ dài thường dùng.
  • Xuất file: bảng hoặc CSV mở được bằng Excel / Google Sheets.
DEV

Dev Client / Backend

Có sẵn danh sách API và schema thay vì tự dò từng màn hình.

  • Danh mục API: method, đường dẫn, header bắt buộc, tham số của từng endpoint.
  • Schema request/response: tên field, kiểu dữ liệu, trường bắt buộc.
  • API graph: endpoint nào gọi trước, endpoint nào phụ thuộc kết quả trước đó.
  • Draft database: gợi ý bảng và cột tương ứng với dữ liệu đã thu được.
GDEV

Game Developer

Có sẵn cấu trúc C# (Unity) và danh sách API thay vì tự dump IL2CPP.

  • Logic trong game: công thức damage, drop rate, regen năng lượng — dẫn đúng class đã khôi phục.
  • API / protocol: endpoint, header, payload server game gọi.
  • SDK map: ads, IAP, analytics, attribution đã nhúng sẵn.
  • Config & bảng dữ liệu: remote config, bảng drop, giá gói nằm ở đâu.

Hai loại dự án

APK

Phân tích app hoặc game Android theo package name (ví dụ com.example.app). App tự tải APK (nếu bật), nhận diện công nghệ (Java, Flutter, React Native, Unity…), phân tích tĩnh và chuẩn bị crawl nội dung / API.

Web

Phân tích website từ URL gốc. Dùng trình duyệt tích hợp; nếu gặp Cloudflare/CAPTCHA bạn hoàn thành trên tab Browser rồi trả lời done.

Không cần thiết bị thật hay máy ảo

Phân tích app và game dựa trên file APK và công cụ tĩnh trên máy bạn. Không yêu cầu root, Frida, hay copy token từ điện thoại.

Bắt đầu trong 3 bước

  1. Cài app Tải bản cho máy bạn (macOS hoặc Windows) và đăng nhập Claude — xem trang cài đặt.
  2. Tạo project Nhập package name của app hoặc game Android, hoặc địa chỉ website, rồi bấm chạy.
  3. Hỏi agent Gõ câu hỏi bằng tiếng thường và nói rõ bạn muốn kết quả ở dạng nào — xem prompt mẫu theo vai trò.
Nội dung sẽ bổ sung vào tài liệu

Các mục đề xuất cho lần cập nhật sau — giúp onboard nhanh hơn:

  1. Thư viện prompt mẫu theo kịch bản (IAP, IAA, rating, tracking, onboarding).
  2. Glossary thuật ngữ bằng tiếng thường (package name, API graph, pipeline…).
  3. Ảnh chụp màn hình Setup / Home / APIs / Browser / Output.
  4. Video ngắn 3–5 phút: từ cài app đến crawl APK đầu tiên.
  5. Trang bảo mật & tuân thủ nội bộ iKame (phạm vi dùng, bản quyền nội dung).
  6. Troubleshooting nâng cao (log trong ~/.ai-crawler, Settings).
  7. Bảng so sánh khi chọn project APK vs Web.
  8. Bản tiếng Anh nếu onboard contractor nước ngoài.
  9. Link tải chính thức + checksum SHA256 theo từng OS.
