Hướng dẫn sử dụng

Tạo project, chạy phân tích (pipeline), rồi hỏi agent bằng tiếng thường. Kết quả nằm ở tab APIs / Output và trong thư mục workspace.

Luồng tổng quan

Mở iAtlas → Setup lần đầu → Home (Agent) → Tạo project APK / Web → Chạy pipeline → Chat + xem Output / APIs

Thanh điều hướng chính: Agent (Home) · Output · Settings. Trong một project: tab Agent · Sources · APIs · Browser.

1. Tạo project APK

  1. Vào Agent → sidebar trái → New project.
  2. Chọn chế độ APK.
  3. Nhập package name Android (ví dụ com.example.app), tên hiển thị tùy chọn.
  4. Bật Download now nếu muốn tải APK ngay (mặc định thường bật).
  5. Tạo project → theo dõi tiến trình tải / khởi tạo trên sidebar.
  6. Khi sẵn sàng, nhấn Run pipeline (có thể ghi mục tiêu crawl trong ô chat trước khi chạy).

Các bước pipeline APK (sidebar): Download → Decompile → Detect framework → Native scan → Source graph → Crawl plan → Replay.

Kết quả chạy nằm dưới ~/.ai-crawler/output/<project>/<timestamp>/ và mở được từ màn Output.

2. Tạo project Web

  1. New project → chọn Web.
  2. Nhập URL gốc (http/https), tên hiển thị tùy chọn.
  3. Run pipeline. Các bước: Browser → Probe → Fingerprint → Crawl.
  4. Nếu gặp Cloudflare / CAPTCHA: mở tab Browser, hoàn thành challenge trên trang, rồi trong chat Agent trả lời done để tiếp tục.
Không dán cookie thủ công

Phiên trình duyệt do app giữ. Chỉ cần xử lý challenge trên tab Browser rồi báo done.

3. Chat với Agent

Hỏi bằng tiếng Việt hoặc tiếng Anh bình thường. Agent ưu tiên câu trả lời dễ hiểu — kết quả + việc cần làm tiếp — và giữ đúng tên endpoint, header, giá trị khi cần.

  • Yêu cầu format output: bảng Markdown, CSV, JSON schema, checklist, Mermaid diagram…
  • Dùng New chat / History / Compact / Clear trên thanh chat khi cần tách luồng.
  • Khi pipeline đang hỏi bạn (AskUser / chờ challenge), trả lời ngay trong ô chat.

4. Các tab — khi nào mở

Agent
Hỏi đáp, theo dõi transcript pipeline, nhập mục tiêu crawl.
Sources
Cây file đã giải mã / nguồn phân tích (khi cần kiểm tra chi tiết kỹ thuật).
APIs
Catalog endpoint đã tìm; chỉnh knobs crawl (max pages, skip detail).
Browser
Chỉ project Web — xem trang, vượt challenge, hỗ trợ crawl.
Output (shell)
Duyệt artifact các lần chạy: report, script crawl, response mẫu…
Settings
AI provider (Claude CLI / API key), đường dẫn tool, diagnostics.

5. Prompt mẫu theo vai trò

PM / BA — IAP “Tóm tắt flow mua hàng trong app (IAP): các màn hình, điều kiện hiện offer, và điểm gọi API thanh toán. Xuất dạng checklist + sơ đồ sequence Mermaid.”
PM / BA — IAA & tracking “Liệt kê các sự kiện tracking / quảng cáo (IAA) tìm được: tên event, khi nào fire, param quan trọng. Bảng Markdown.”
PM / BA — rating “App khi nào hiện popup rating? Điều kiện, tần suất, copy nếu có trong nguồn. Trả lời ngắn rồi kèm bảng bằng chứng.”
Content “Crawl / liệt kê cấu trúc nội dung listing (chuyên mục, field tiêu đề/mô tả/ảnh). Xuất taxonomy dạng bảng để team content tham khảo.”
Dev — API graph “Vẽ API graph các endpoint liên quan feed và detail theo id: method, path, header bắt buộc, quan hệ gọi. Mermaid hoặc bảng.”
Dev — schema & DB “Với endpoint …/feed: mô tả request/response field (kiểu, bắt buộc?). Đề xuất draft bảng database tương ứng (tên cột + kiểu).”
Mọi người — format tùy ý “Trả lời bằng CSV: cột Feature, Flow step, API path, Ghi chú — chỉ các bước liên quan onboarding.”

6. Giới hạn quan trọng

  • Phân tích tĩnh / offline trên artifact trong workspace — không cần máy ảo, root, Frida, MITM.
  • Không yêu cầu bạn copy token / session từ điện thoại đang chạy app.
  • Một số bước (ví dụ secret trong file native) do agent tự xử lý trên máy; bạn chỉ cung cấp tài khoản đăng nhập nếu thật sự cần (email/password bạn đã có).
  • Chỉ chạy một pipeline tại một thời điểm; chat project khác vẫn dùng được.
